# トレッド比 往復テスト結果まとめ

前進200mm → 後退200mm を20回繰り返した結果（各トレッド比）。

## 集計値の比較

| 項目 | トレッド比 0.5 | トレッド比 1.0 | トレッド比 2.0 |
|------|----------------|----------------|----------------|
| **直進誤差 (mm)** | 平均 -3.5 / 最大絶対値 4.0 | 平均 -3.3 / 最大絶対値 4.0 | 平均 -3.4 / 最大絶対値 4.0 |
| **後退誤差 (mm)** | 平均 6.1 / 最大絶対値 9.0 | 平均 4.4 / 最大絶対値 5.0 | 平均 3.7 / 最大絶対値 4.0 |
| **終了時 距離 (mm)** | 平均 32.2 / 最大 53.0 | 平均 11.9 / 最大 22.0 | 平均 0.9 / 最大 5.0 |
| **終了時 向き (deg)** | 最後 -9.3 / 最大絶対値 9.3 | 最後 -1.4 / 最大絶対値 1.4 | 最後 2.2 / 最大絶対値 2.2 |

## 傾向

- **トレッド比 0.5**: 距離・向きともに誤差が大きく、20往復後に約53mm・約9°ずれる。
- **トレッド比 1.0**: 0.5より改善。終了距離は約22mm、向きは約1.4°程度。
- **トレッド比 2.0**: 最も良好。終了距離は約5mm以内、向きも約2.2°以内に収まる。

## 結論

このロボット・床条件では **トレッド比 2.0** が最も直進・往復のズレが小さく、20往復後もほぼ元の位置に戻る。
