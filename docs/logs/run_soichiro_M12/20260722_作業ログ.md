## 変更概要

50mm 前進と 50mm 後退の動作を `for` ループで繰り返せるようにした。

---

## 変更前のコード

```python
await robot.straight(50, speed=500)
await robot.straight(-50, speed=500)
```

---

## 変更後のコード

```python
REPEAT_COUNT = 3  # 繰り返し回数（必要に応じて変更）

for _ in range(REPEAT_COUNT):
    await robot.straight(50, speed=500)
    await robot.straight(-50, speed=500)
```

| # | 変更内容 | 変更前 | 変更後 |
|---|---|---|---|
| 1 | 前進/後退の繰り返し | 1回のみ実行 | `REPEAT_COUNT` 回ループ |

## 動作シーケンス（変更後）

1. **50mm 前進**（500mm/s）→ **50mm 後退**（500mm/s）を 3 回繰り返す
