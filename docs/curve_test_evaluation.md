# カーブテスト結果の評価

**条件**: 半径200mm・90°・10試行

## 距離誤差（弧の長さ）

| 項目 | 値 | 評価 |
|------|-----|------|
| 目標 | 314mm | 2π×200×90/360 ≒ 314で正しい |
| 平均誤差 | -2.9mm | 常に約3mm短い（系統的な短め） |
| 最大絶対値 | 4.2mm | 314mmに対して約1.3% |

- 誤差のばらつきは小さい（310〜312mmに集中）。
- 実運用では「やや短い」傾向を補正するなら、目標距離を +3mm 程度にしてもよい。

## 向き誤差（曲がり終わりの角度）

| 項目 | 値 | 評価 |
|------|-----|------|
| 平均誤差 | -0.3° | ほぼ目標どおり |
| 最大絶対値 | 0.8° | 90°に対して約0.9% |

- 89.2°〜90.2°の範囲で収まっており、再現性も良い。

## 総合

- **距離**: 系統的に約3mm短いが、ばらつきは小さく、許容範囲内。必要なら +3mm 補正で十分。
- **向き**: 平均・最大とも良好で、カーブ後の姿勢は信頼できる水準。
- **再現性**: 10回とも似た値で、条件が安定している。

**結論**: このカーブ設定（半径200mm・90°）としては「問題なく使える」レベルです。本番で細かい位置が気になる場合は、距離だけ +2〜3mm の補正をかけると安心です。
