# SD（誤差のバラつき）を下げる方法

旋回テストで「誤差の標準偏差 SD」が大きい＝毎回の当たりどころがバラついている状態です。  
以下を試すと、**再現性（SDの低下）** が期待できます。

---

## 1. ハード・メカニカル

| 対策 | 説明 |
|------|------|
| **トレッドを広げる** | タイヤ間距離 T を大きくすると旋回が穏やかになり、スリップの影響が減りやすい。SD が下がりやすい。 |
| **グリップをそろえる** | 左右同じタイヤ・摩耗状態。タイヤや床の汚れを拭く。 |
| **重心・荷重** | 左右対称にする。緩いパーツやバッテリー位置を固定。 |
| **ガタ・バックラッシュ** | 車軸・ギアのゆるみを減らす。駆動系をしっかり固定。 |

---

## 2. ソフト・制御（run_test_ayumu.py で変更可能）

| 対策 | 設定例 |
|------|--------|
| **旋回後に待ってから計測** | `TURN_ACCURACY_SETTLE_MS = 150`（既定で150ms）。振動・滑りが落ち着いてから角度を読むと SD が下がりやすい。200〜300ms に増やして試してもよい。 |
| **旋回角速度を遅くする** | `TURN_ACCURACY_RATE = 150` など（deg/s）。遅めにするとオーバーシュートやバラつきが減りやすい。 |
| **setup.py の PID・旋回設定** | 旋回の加速度・角速度を控えめにすると、毎回の挙動が揃いやすい。 |

---

## 3. 測定のやり方

| 対策 | 説明 |
|------|------|
| **リセット後の待ち** | `reset_pose` のあと、IMU が落ち着くまで少し待ってから旋回を始めると安定しやすい（必要なら `reset_pose` 内の wait を延ばす）。 |
| **同じ条件で比較** | 床・電池残量・荷重をできるだけ同じにして、変更するのは「トレッド（タイヤ位置）」や「旋回速度」だけにする。 |

---

## 4. 環境

- **同じ床**でテストする（カーペット／フロアで結果が変わる）。
- 床の**汚れ・砂**を取る。
- **平らな場所**で旋回させる。

---

## コードで入れた変更（SD 対策）

- **`TURN_ACCURACY_SETTLE_MS = 150`**  
  旋回完了後、150ms 待ってから `heading` と `distance` を読むようにした。  
  振動や微少な滑りが収まってから計測するので、SD が下がりやすい。
- **`TURN_ACCURACY_RATE`**  
  コメントで「遅めにすると SD が下がりやすい」と記載。  
  `None` のままでもよいが、SD が大きいときは 150〜200 deg/s などに設定して試すとよい。

SD がまだ大きい場合は、上から順に「トレッド幅」「旋回速度」「旋回後待ち時間」を優先して調整すると効果が出やすいです。
